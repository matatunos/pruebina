Instalación del APK

Método 1: ADB (Línea de Comandos)

Prerrequisitos

  • Android Debug Bridge (ADB) instalado
  • Dispositivo conectado vía USB
  • Depuración USB habilitada en el dispositivo

Pasos

  1. Conecta tu dispositivo Android vía USB
  2. Abre terminal o símbolo del sistema
  3. Navega a la carpeta con el APK
  4. Ejecuta el comando:
    adb install -r agenda-app.apk
  5. Espera el mensaje: "Success"
  6. La app aparecerá en tu lista de aplicaciones

Método 2: Instalación Manual

Pasos

  1. Copia agenda-app.apk a tu dispositivo (vía USB o descarga)
  2. Abre Administrador de archivos
  3. Navega a la carpeta donde guardaste el archivo
  4. Toca agenda-app.apk
  5. Si aparece aviso de "Fuentes desconocidas", toca Instalar de todas formas
  6. Espera a que termine la instalación
  7. Toca ABRIR para ejecutar la app
✓ Instalación exitosa: La app aparecerá en tu biblioteca de aplicaciones con el icono morado.

Primeros Pasos

Abrir la Aplicación

  1. En tu dispositivo, toca el icono de Agenda Telefónica
  2. Espera a que se cargue la pantalla principal
  3. Verás la lista vacía de contactos (si es la primera vez)

Pantalla Principal

La pantalla principal muestra:

  • Barra superior: Título "AGENDA TELEFÓNICA"
  • Área principal: Lista de contactos (inicialmente vacía)
  • Botón flotante (+): Para agregar nuevos contactos

Agregar tu Primer Contacto

  1. Toca el botón circular "+" en la esquina inferior derecha
  2. Se abre la pantalla "NUEVO CONTACTO"
  3. Ingresa los datos:
    • Nombre: Nombre completo (opcional)
    • Teléfono: Número de teléfono (obligatorio)
    • Email: Correo electrónico (opcional)
  4. Toca el botón "GUARDAR"
  5. Regresa a la lista y verás el contacto agregado
ℹ️ Información importante: El campo "Teléfono" es obligatorio. Sin un número de teléfono, no se puede guardar el contacto.

Operaciones Básicas

Editar un Contacto

  1. En la lista de contactos, toca la tarjeta del contacto que deseas editar
  2. Se abre la pantalla de edición con los datos actuales
  3. Modifica los campos necesarios
  4. Toca "GUARDAR" para confirmar cambios
  5. Regresa automáticamente a la lista

Eliminar un Contacto

  1. En la lista, toca la tarjeta del contacto a eliminar
  2. Se abre la pantalla de edición
  3. Toca el botón rojo "ELIMINAR"
  4. Se mostrará un diálogo de confirmación
  5. Toca "CONFIRMAR" para eliminar
  6. El contacto se elimina permanentemente
⚠️ Advertencia: La eliminación es permanente y no se puede deshacer. Asegúrate de querer eliminar el contacto antes de confirmar.

Almacenamiento de Datos

Tipo de Almacenamiento: SQLite (Almacenamiento local del dispositivo)

Privacidad: Todos tus contactos se almacenan exclusivamente en tu dispositivo. No se envía información a ningún servidor externo.

Persistencia: Los contactos se guardan permanentemente incluso si cierras o desinstales la app (hasta que los elimines manualmente).

Permisos Requeridos

La app solo requiere acceso al almacenamiento interno para guardar y leer los contactos.

  • ✓ WRITE_INTERNAL_STORAGE - Guardar contactos
  • ✓ READ_INTERNAL_STORAGE - Leer contactos
  • ✗ NO requiere acceso a internet
  • ✗ NO requiere acceso a cámara
  • ✗ NO requiere acceso a micrófono
✓ Seguridad: La aplicación no recopila ni comparte datos personales. Tu privacidad es importante para nosotros.

Solución de Problemas

La app no abre después de instalar

Problema: La aplicación no se abre al tocar el icono.

Soluciones:

  1. Verifica que tengas Android 5.0 o superior
  2. Desinstala la app completamente
  3. Ejecuta: adb install -r agenda-app.apk
  4. Borra el caché: adb shell pm clear com.agenda.telefonos
  5. Reinicia tu dispositivo

No se guarda el contacto

Problema: Al tocar "Guardar", el contacto no se agrega a la lista.

Soluciones:

  1. Verifica el campo teléfono: Es obligatorio y no puede estar vacío
  2. Espera a que desaparezca el teclado antes de guardar
  3. Verifica el espacio en disco: Asegúrate de tener al menos 50 MB
  4. Intenta nuevamente: A veces los toques rápidos no registran
  5. Reinicia la app si persiste el problema

El email no se válida

Problema: No puedo guardar un contacto con email.

Soluciones:

  1. Verifica el formato: usuario@dominio.com
  2. No incluyas espacios en el email
  3. El email es opcional: puedes dejarlo vacío
  4. Si no necesitas email, borra el contenido y deja el campo en blanco

Se eliminó un contacto por error

⚠️ Limitación actual: No hay papelera de reciclaje o recuperación de datos. En futuras versiones se agregará esta funcionalidad.

Por ahora, sé cuidadoso con el botón "Eliminar".
