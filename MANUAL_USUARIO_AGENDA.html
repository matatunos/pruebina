1. Introducción

Agenda Telefónica es una aplicación Android moderna diseñada para gestionar tus contactos de manera fácil e intuitiva. Permite agregar, editar, buscar y eliminar contactos con información completa como nombre, teléfono y correo electrónico.

Requisitos del Sistema

  • ✅ Android 5.0+ (API 21 o superior)
  • ✅ Pantalla de 4.5 pulgadas mínimo recomendado
  • ✅ 50 MB de espacio disponible
  • ✅ Conexión a internet NO requerida (datos locales)

2. Instalación del APK

Opción 1: Instalación por ADB (Recomendado)

Si tienes Android Debug Bridge (ADB) instalado:

adb install -r agenda-app.apk

Opción 2: Instalación Manual

  1. Copia el archivo agenda-app.apk a tu dispositivo Android
  2. Abre el Gestor de Archivos de tu dispositivo
  3. Navega hasta el archivo agenda-app.apk
  4. Toca el archivo para iniciar la instalación
  5. Autoriza la instalación desde "Fuentes desconocidas" si es necesario
  6. Toca el botón "INSTALAR"
  7. Espera a que la instalación se complete
  8. Toca "ABRIR" para ejecutar la app

Opción 3: Actualizar APK Existente

adb install -r agenda-app.apk

La bandera "-r" permite reinstalar reemplazando la versión anterior sin perder datos.

4. Agregar o Editar un Contacto

Campos del Formulario

Campo Tipo Requerido
Nombre Texto No
Teléfono Texto ✓ Sí
Email Texto No

Validaciones

  • ✅ Nombre: Campo opcional
  • ✅ Teléfono: Campo obligatorio
  • ✅ Email: Se valida si se ingresa (formato válido)
9:41
🔷 NUEVO CONTACTO

Cómo Agregar un Nuevo Contacto

  1. En la pantalla principal, toca el botón flotante "➕"
  2. Se abre la pantalla de "NUEVO CONTACTO"
  3. En el campo "Nombre", escribe el nombre completo (opcional)
  4. En el campo "Teléfono", escribe el número de teléfono (obligatorio)
  5. En el campo "Email", escribe el correo electrónico (opcional)
  6. Toca el botón "Guardar"
  7. Se regresa automáticamente a la lista de contactos
  8. El nuevo contacto aparecerá en la lista

Cómo Editar un Contacto Existente

  1. En la lista de contactos, toca la tarjeta del contacto a editar
  2. Se abre la pantalla de edición con los datos actuales
  3. Toca el campo que deseas modificar
  4. Borra el contenido anterior y escribe el nuevo valor
  5. Repite para cada campo a cambiar
  6. Toca el botón "Guardar"
  7. Los cambios se guardan inmediatamente
  8. Regresa a la lista de contactos

Cómo Eliminar un Contacto

  1. En la lista de contactos, toca la tarjeta del contacto a eliminar
  2. Se abre la pantalla de edición
  3. Toca el botón "Eliminar" (botón rojo)
  4. Se mostrará un diálogo de confirmación
  5. Toca "CONFIRMAR" para eliminar permanentemente
  6. El contacto se elimina de la base de datos
  7. Regresa a la lista de contactos

⚠️ Advertencia de Eliminación

La eliminación es permanente y no se puede deshacer. Asegúrate de que deseas eliminar el contacto antes de confirmar la acción. En futuras versiones, se añadirá una papelera de reciclaje para recuperar contactos eliminados.

7. Solución de Problemas

❓ La app no abre después de instalar

Solución:

  1. Verifica que tengas Android 5.0 o superior
  2. Intenta reinstalar el APK: adb install -r agenda-app.apk
  3. Borra el caché: adb shell pm clear com.agenda.telefonos
  4. Reinicia tu dispositivo

❓ No se guarda el contacto

Solución:

  1. Verifica que el campo "Teléfono" esté completo (es obligatorio)
  2. Toca correctamente el botón "Guardar"
  3. Espera a que desaparezca el teclado antes de guardar
  4. Verifica que haya espacio disponible en el dispositivo

❓ Se eliminó un contacto por error

Limitación actual: No hay recuperación de contactos eliminados. Recomendación: Sé cuidadoso al presionar el botón "Eliminar". En futuras versiones se añadirá una papelera de reciclaje.

❓ El email no se válida correctamente

Solución:

  1. Verifica el formato: usuario@dominio.com
  2. No incluyas espacios en blanco
  3. El campo es opcional: puedes dejarlo en blanco
  4. Asegúrate de escribir el email correctamente

❓ La app se cierra inesperadamente

Solución:

  1. Reinicia tu dispositivo
  2. Desinstala y reinstala la app
  3. Asegúrate de tener espacio suficiente en memoria
  4. Actualiza tu dispositivo a la última versión de Android

8. Preguntas Frecuentes (FAQ)

¿Hay límite de contactos?

Respuesta: Teóricamente puedes guardar miles de contactos. De forma práctica, depende del espacio disponible en tu dispositivo. Se recomienda mantener hasta 1000 contactos para mejor rendimiento.

¿Puedo exportar mis contactos?

Respuesta actual: No hay opción de exportación en v1.0. Próximas versiones: Se añadirá soporte para exportar a CSV y vCard.

¿Hay sincronización con Google Contacts?

Respuesta actual: No, es almacenamiento completamente local. Futuro: Se planea integración con Google Contacts y OneDrive.

¿Puedo agrupar o etiquetar contactos?

Respuesta actual: No hay categorías o grupos. Futuro: Se añadirán favoritos, grupos y búsqueda avanzada.

¿Hay búsqueda de contactos?

Respuesta actual: No hay búsqueda en v1.0. Futuro: Se implementará búsqueda rápida por nombre y teléfono.

¿Puedo hacer llamadas desde la app?

Respuesta actual: No hay integración de llamadas. Futuro: Se añadirá acceso directo para llamar mediante el icono de teléfono.

10. Permisos Necesarios

La app requiere acceso a almacenamiento local para guardar los contactos en la base de datos SQLite.

Permisos Requeridos

  • ✅ android.permission.WRITE_INTERNAL_STORAGE - Guardar contactos
  • ✅ android.permission.READ_INTERNAL_STORAGE - Leer contactos

Permisos NO Requeridos

  • ❌ INTERNET - La app no necesita conexión
  • ❌ CALL_PHONE - No realiza llamadas
  • ❌ SEND_SMS - No envía mensajes
  • ❌ CAMERA - No usa la cámara
